# 周文璐 · 个人简历网站

## 使用方法

### 本地查看
直接用浏览器打开 `index.html` 即可。

### 🌐 分享给他人（部署上线）

推荐使用 **GitHub Pages**，免费且简单：

#### 方法一：GitHub Pages（推荐）

1. 注册 [GitHub](https://github.com) 账号
2. 新建仓库，命名为 `resume` 或任意名称
3. 将 `index.html` 上传到仓库根目录
4. 进入仓库 → Settings → Pages
5. Source 选择 `main` 分支，点击 Save
6. 等待1-2分钟，访问 `https://你的用户名.github.io/resume/` 即可

**每次更新简历后：**
- 在网页上点击右下角「📥 导出」按钮
- 将导出的 HTML 文件替换 GitHub 仓库中的旧文件
- 网站自动更新

#### 方法二：直接发送 HTML 文件
- 点击右下角「📥 导出」按钮，导出最新版 HTML
- 将导出的 `.html` 文件直接发送给对方
- 对方用浏览器打开即可查看

#### 方法三：Netlify / Vercel
- 注册 [Netlify](https://netlify.com)，拖拽 `index.html` 即可上线
- 获得一个 `xxx.netlify.app` 的链接，可直接分享

## 功能说明

| 功能 | 操作 |
|------|------|
| 📷 上传照片 | 点击头像右下角相机图标 |
| 🔍 查看离职原因 | 点击工作经历卡片中的「查看离职原因」按钮 |
| ✏️ 编辑模式 | 点击右下角「编辑」按钮，可增删改工作经历和项目 |
| 🖼️ 作品集 | 编辑模式下可上传图片或粘贴图片链接 |
| 📥 导出 | 将当前所有数据导出为独立HTML文件，用于部署 |
| 🔄 重置 | 编辑模式下可恢复默认数据 |
